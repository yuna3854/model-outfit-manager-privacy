Model Outfit Manager プライバシーポリシー

最終更新日：2026年9月28日

1. 本拡張機能について

Model Outfit Managerは、配信者が使用しているVTube Studioモデルの衣装、髪型、アクセサリー、プリセットなどの情報を視聴者に表示するためのTwitch拡張機能です。

2. 取得・利用する情報

本拡張機能は、表示や連携に必要な範囲で、モデル名、衣装、髪型、アクセサリー、プリセットなどの設定情報を扱います。視聴者の氏名、住所、決済情報などを取得することを目的としていません。

3. VTube Studioとの連携

VTube Studioとの連携では、配信者側の連携サーバー（Bridge）を介して情報を取得する構成を想定しています。視聴者の端末から配信者のPC上のVTube Studioへ直接接続するものではありません。

4. 情報の保存・第三者提供

設定情報の保存方法や保存期間は、利用するTwitchの機能および連携サーバーの構成に依存します。法令に基づく場合を除き、取得した情報を第三者へ販売・提供することを目的としません。

5. お問い合わせ

お問い合わせ先は、拡張機能の公開ページまたは配信者が案内する連絡先をご確認ください。

6. ポリシーの変更

必要に応じて本ポリシーを変更する場合があります。変更後の内容はこのページで公開します。
